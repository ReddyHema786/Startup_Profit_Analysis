# Startup Profit Analysis & Prediction

## Project Overview

This project analyzes startup spending patterns and profitability using Python, Machine Learning, and Power BI.

The main objective is to understand how Research & Development, Administration, Marketing spending, and State are associated with startup Profit. A Linear Regression model is developed to predict Profit, and an interactive Power BI dashboard is created to present the findings.

---

## Objectives

- Analyze startup spending and profitability.
- Understand the relationship between different spending categories and Profit.
- Compare startup profitability across different States.
- Identify the factors that have the strongest relationship with Profit.
- Build a Linear Regression model to predict Profit.
- Evaluate the performance of the regression model.
- Create an interactive Power BI dashboard.
- Generate useful business insights for data-driven decision making.

---

## Dataset

The dataset contains 50 startup records and 5 columns.

### Columns

| Column | Description |
|---|---|
| RD_Spend | Spending on Research and Development |
| Administration | Administration expenditure |
| Marketing_Spend | Marketing expenditure |
| State | State where the startup operates |
| Profit | Profit generated by the startup |

### Target Variable

`Profit`

### Input Features

- `RD_Spend`
- `Administration`
- `Marketing_Spend`
- `State`
